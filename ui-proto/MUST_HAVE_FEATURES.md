# Cliplo Must-Have Feature List

Cliplo's first serious release should deliver one clear promise:

> Copy something once, then find and reuse it instantly from anywhere.

## Core Capture

- Reliable automatic clipboard capture
- Manual paste capture when system access is limited
- Source-app tracking
- Capture timestamps
- Duplicate detection
- Text clip support
- Link clip support
- Image clip support
- Pause capture switch
- App exclusion list
- Clear capture status
- Capture error and recovery states

## Smart Organization

- Automatic clip classification
- Smart Collections
- Collections for links, code, contacts, images, messages, notes, and sensitive data
- Custom folders
- Manual tags
- Automatic titles for long clips
- Rules for assigning clips to folders
- Recently reused collection
- Frequently reused collection
- Pinned clips
- Favorite clips
- Archived clips
- Edit clip content
- Move clips between folders

## Search and Discovery

- Fast on-device full-text search
- Search by clip content
- Search by source app
- Search by folder
- Search by tag
- Search by clip type
- Search by date range
- Filter pinned, favorite, archived, and sensitive clips
- Combine multiple filters
- Highlight matching search text
- Open clips from the main app or keyboard

## Clip Actions

- Copy clip back to the system clipboard
- One-tap paste
- Open links in the browser or source app
- Share through the Android Sharesheet
- Print or export clips where supported
- Duplicate clips
- Delete individual clips
- Bulk select clips
- Bulk copy, move, archive, favorite, pin, and delete
- Undo accidental deletion or movement
- Full clip detail view

## Keyboard Access

- Access recent clips while typing
- Search the full clip library from the keyboard
- Browse Smart Collections from the keyboard
- Browse custom folders from the keyboard
- Paste a single clip without opening Cliplo
- Run a saved paste sequence
- Access protected clips after authentication
- Keep keyboard access fast and usable in other apps

## Secure Vault

- Protect individual clips
- Protect complete folders
- Biometric authentication
- PIN fallback
- Authenticate before viewing sensitive content
- Authenticate before copying or pasting sensitive content
- Detect passwords, payment details, addresses, and authentication codes
- Suggest moving sensitive content into the Vault
- Redact sensitive previews and notifications
- Encrypt Vault content locally

## Smart Reuse

- Smart paste suggestions
- Recently reused clips
- Frequently reused clips
- Context-aware suggestions where Android permissions allow
- Templates with variables
- Saved paste queues
- Paste sequences containing 3 to 8 clips
- Reorder paste sequence items
- Save and reuse common sequences
- Confirm before pasting protected clips

## Privacy and Offline Behavior

- Offline-first operation
- No account required for core functionality
- Local clip storage by default
- Local classification for basic clip types
- No clip content sent to a server for core features
- Local encrypted storage for protected data
- Encrypted local export and import where supported
- Clear permission explanations
- Permanent delete-all-data action
- Privacy controls for source-app tracking

## Reliability and Quality

- Safe behavior when clipboard permission is unavailable
- Database backup and restore
- Crash recovery
- Migration support for stored clip data
- Empty, loading, locked, disabled, and error states
- Screen-reader support
- Minimum 44dp touch targets
- Light and dark themes
- Reduced-motion support
- Fast launch
- Smooth scrolling with large clip libraries
- Real-device testing across Android versions

## App Experience

- Bottom capture and control panel
- One-handed interaction
- Left-handed and right-handed layouts
- Main feed with recent clips
- Smart Collection navigation
- Folder navigation
- Clip detail sheet
- Long-press action menu
- Clear onboarding
- Seven-day full-feature trial
- Free-plan limit messaging
- Pro upgrade instructions

## Free and Pro Rules

### Full Trial

- Seven days of full functionality
- Full Smart Collections
- Unlimited practical organization
- Custom folders and tags
- Vault
- Keyboard access
- Advanced search and filters
- Templates and paste sequences when available

### Free Version

- Maximum of 50 stored clips
- Basic capture and copy access
- Recent clip access
- Limited advanced organization
- No unrestricted custom folder organization
- Clear messaging before reaching the limit
- Existing older clips should be retained rather than silently deleted
