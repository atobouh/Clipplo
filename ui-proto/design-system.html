02 · Foundation

The product should feel quiet.

These principles protect Cliplo from becoming an administration tool. Every new surface must make memory easier, not make Cliplo more visible.

01

Quiet by default

Reduce chrome. Let saved material be the hero and reveal complexity only when it helps.

02

One clear action

Every surface has an obvious next step. Power stays available without being permanently exposed.

03

Memory has a shape

Source, time, type, and enriched previews make a clip recognizable before it is opened.

04

Keep the user in control

Cliplo can notice patterns and suggest organization, but it never silently takes ownership.

03 · Product model

What Cliplo knows.

Design around the saved object and its useful transformations, not around screens or database fields.

Capture

The original thing the user copied.

  • Raw valueNever silently destroy the original.
  • SourceWhere it came from, when known.
  • TimeWhen it entered memory.

Enrichment

A more tangible representation.

  • Link identityCanonical URL and cleaned tracking.
  • PreviewTitle, image, account, duration, type.
  • ConfidenceGraceful fallback when metadata is missing.

Reuse

The reason the object exists.

  • CopyPrimary action for every reusable clip.
  • OpenReturn to the source when useful.
  • OrganizeCollections, Pin, Favorite, Vault.

07 · Interaction

States are part of the design.

Premium is the quality of the transition, not the still screenshot. Every important component needs a named response.

Default

Ready to capture
Quiet, discoverable, available.

Focus

Search your library
Accent ring, no layout jump.

Pressed

Copied
100–180ms tactile response.

Disabled

Unavailable action
Reduced, still legible.

Error

Preview unavailable
Name the problem and recovery.

Loading

Finding link preview…
Use language, not only a spinner.

Do

Behavior that makes Cliplo feel considered.

✓ Preserve contextShow source, time, type, and the best available preview before asking for an action.
✓ Suggest, do not seizeWhen Cliplo notices a pattern, ask before creating a collection or changing state.

Do not

Patterns that turn a memory tool into a dashboard.

× Metadata wallsDo not show every field because it exists in the model.
× Invisible automationDo not move, rewrite, or group saved material without a clear user decision.

09 · Content

Say less. Mean more.

Cliplo’s language should sound like a calm assistant that noticed something useful, not like a system asking the user to configure itself.

Voice chart

PreferAvoid
“Ready to paste”“Clipboard item detected”
“Create a YouTube collection?”“Automation rule available”
“Preview unavailable”“Metadata fetch failed”
“Nothing matched that”“No results found”
“Copied”“Operation successful”

Metadata hierarchy

When link data is available, rank it in this order:

  1. 1 · IdentityTitle, account, repository, or domain.
  2. 2 · RecognitionThumbnail, favicon, source, content type.
  3. 3 · ActionCopy, Open, Add to collection.
  4. 4 · ContextTime and secondary metadata.
10 · Build rules

Ship the system, not just the screenshot.

These rules apply when the prototype becomes Jetpack Compose. A component is not complete until its behavior and failure states survive translation.

Implementation contract

{ "rawUrl": "preserved", "cleanUrl": "displayed", "previewStatus": "ready | loading | unavailable", "primaryAction": "copy", "organization": "explicit or confirmed" }
